# 📘 MyEnglish — 개인 영어공부 플랫폼

혼자서 꾸준히 영어를 공부할 수 있는 가벼운 웹앱입니다.
**서버·로그인·설치가 필요 없고**, 모든 학습 데이터는 브라우저(localStorage)에 저장됩니다.

## 🚀 사용 방법

1. `english-app/index.html` 파일을 브라우저에서 열기만 하면 됩니다.
   - 더블클릭하거나, 간단히 로컬 서버로 열어도 됩니다:
     ```bash
     cd english-app
     python3 -m http.server 8000
     # 브라우저에서 http://localhost:8000 접속
     ```
2. 처음 실행하면 기초 단어 60여 개가 자동으로 채워집니다.

## ✨ 주요 기능

| 탭 | 설명 |
|---|---|
| 📅 **오늘 복습** | 플래시카드 + **간격 반복(SRS)** 알고리즘으로 외운 단어를 최적의 시점에 자동 복습. `다시 / 어려움 / 알맞음 / 쉬움`으로 채점하면 다음 복습 간격이 조정됩니다. |
| 📚 **단어장** | 나만의 단어 추가·편집·삭제, 검색, 숙련도 표시(새 단어 / 학습 중 / 복습 중 / 완료). |
| 💬 **예문 학습** | 예문 속 단어를 맞히는 **빈칸 채우기**. 힌트·정답 확인·발음 듣기 지원. |
| 🧩 **기초 문법** | be동사, 일반동사, 관사, 시제, 전치사 등 **기초 문법 10강** + 강별 미니 퀴즈. |
| 📊 **학습 통계** | 연속 학습일(스트릭), 누적 복습, 정답률, 최근 14일 학습량 그래프, 단어 숙련도 분포. |

## 🔧 기타

- 🔊 **발음 듣기**: 브라우저 음성합성(TTS)으로 단어·문장을 읽어줍니다.
- 🌙 **다크 모드**: 우측 상단 버튼으로 전환.
- 💾 **백업/복원**: 통계 탭에서 데이터를 JSON으로 내보내거나 가져올 수 있습니다.

## 🗂 파일 구성

```
english-app/
├── index.html    # 화면 구조
├── styles.css    # 스타일 (라이트/다크 테마)
├── app.js        # 핵심 로직 (SRS·단어장·통계·문법 등)
├── data.js       # 시드 단어 데이터
└── grammar.js    # 기초 문법 레슨 데이터
```

순수 HTML/CSS/JavaScript로만 만들어져 별도 빌드나 의존성이 없습니다.
